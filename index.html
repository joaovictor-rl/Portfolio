02 — 2026 · Projeto pessoal

Cursor

Calculadora de trajetória acadêmica para alunos da UFPA. Você envia o PDF do histórico do SIGAA e vê, em uma página, em que ponto do curso está e quanto falta para se formar.

Abrir o site Ver código

Hospedado no plano gratuito do Render: se o site estiver parado, o primeiro acesso pode levar até um minuto.

O que ele mostra —

  • CRG e CR de cada semestre, com gráfico
  • Carga horária cumprida e exigida
  • Disciplinas concluídas e pendentes
  • Previsão de formatura pelo ritmo do aluno
  • Simulador do próximo semestre

Como funciona —

  • O React envia o PDF para uma API em FastAPI
  • pdfplumber e expressões regulares leem o histórico
  • pandas organiza os dados e calcula CR, horas e previsão
  • Recharts desenha os gráficos

Privacidade —

  • O PDF é lido na memória e descartado
  • Sem banco de dados: nada fica salvo
  • Validação com Pydantic e cabeçalhos de segurança

Qualidade —

  • 25 testes automatizados com pytest
  • Docker e deploy automático no Render
  • Roda no Windows com um único comando
