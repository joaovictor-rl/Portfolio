01 — 2026 · Em desenvolvimento

Musa

Assistente com IA que tira dúvidas dos alunos da Escola de Música da UFPA sobre cursos, editais e funcionamento da escola. O modelo roda num servidor da própria escola, sem API paga, e cada resposta cita o documento de onde veio.

Funciona só na rede interna da UFPA, por isso não tem link público.

O que ela faz —

  • Responde dúvidas sobre a escola em linguagem simples
  • Cita a fonte de cada resposta
  • Recusa perguntas fora do tema
  • Interface própria, com tema claro e escuro

Como funciona —

  • LLM local com Ollama (Qwen3)
  • RAG: embeddings (bge-m3) e busca no PostgreSQL com pgvector
  • Coleta automática das páginas e editais do site da escola
  • Back-end em FastAPI com respostas em streaming

Segurança —

  • Filtro por similaridade barra prompt injection antes do modelo
  • Documentos com dados pessoais são descartados (LGPD)
  • Servidor Ubuntu com firewall só para a rede da UFPA

Próximo passo —

  • Avaliar as respostas com perguntas reais de alunos
  • Melhorar a precisão e a velocidade

02 — 2026 · Plugin para o Tainacan

Thesaurus Indexer

Plugin para o Tainacan, plataforma de acervos digitais, que sugere termos de indexação para itens de museus e arquivos usando IA e as taxonomias que a própria instituição já usa.

Ver código

Nada é gravado sem a aprovação do profissional.

O que ele faz —

  • Lê a ficha do item: título, descrição, material, procedência
  • Sugere termos das taxonomias da própria coleção
  • Separa conceitos novos como ideia de termos
  • Aceita tesauros em CSV, SKOS ou JSON

Como funciona —

  • Plugin em PHP para WordPress e Tainacan
  • LLM por API compatível com a OpenAI (Groq ou Ollama)
  • Cada termo sugerido é conferido na lista antes de aparecer
  • Segue as etapas da indexação de Kobashi (2008)

Próximo passo —

  • Estudo de caso com peças reais de acervo
  • Publicação no diretório de plugins do WordPress

Crônica

Versões, comparação e escrita em grupo de artigos acadêmicos. Cada vez que o pesquisador salva, fica uma versão, e dá para ver frase por frase o que mudou.

Abrir o site Ver código

Hospedado no plano gratuito do Render: se o site estiver parado, o primeiro acesso pode levar até um minuto.

O que ele faz —

  • Editor no site, sem precisar saber LaTeX
  • Histórico de versões e comparação frase a frase
  • PDF de cada versão nos formatos ABNT, SBC e IEEE
  • Importa e exporta projetos do Overleaf
  • Organizações, convites e coautores

Como funciona —

  • API REST em FastAPI
  • SQLAlchemy com PostgreSQL (Neon) ou SQLite
  • Arquivos guardados por conteúdo, como no Git
  • PDF gerado no servidor com reportlab

Segurança —

  • Senhas com bcrypt e login com JWT
  • Limite de tentativas contra força bruta
  • Exportar e apagar a própria conta

Qualidade —

  • 113 testes automatizados com pytest
  • Testes no PostgreSQL pelo GitHub Actions
  • Deploy no Render só quando os testes passam

04 — 2026 · Projeto pessoal

Cursor

Calculadora de trajetória acadêmica para alunos da UFPA. Você envia o PDF do histórico do SIGAA e vê, em uma página, em que ponto do curso está e quanto falta para se formar.

Abrir o site Ver código

Hospedado no plano gratuito do Render: se o site estiver parado, o primeiro acesso pode levar até um minuto.

O que ele mostra —

  • CRG e CR de cada semestre, com gráfico
  • Carga horária cumprida e exigida
  • Disciplinas concluídas e pendentes
  • Previsão de formatura pelo ritmo do aluno
  • Simulador do próximo semestre

Como funciona —

  • O React envia o PDF para uma API em FastAPI
  • pdfplumber e expressões regulares leem o histórico
  • pandas organiza os dados e calcula CR, horas e previsão
  • Recharts desenha os gráficos

Privacidade —

  • O PDF é lido na memória e descartado
  • Sem banco de dados: nada fica salvo
  • Validação com Pydantic e cabeçalhos de segurança

Qualidade —

  • 25 testes automatizados com pytest
  • Docker e deploy automático no Render
  • Roda no Windows com um único comando
